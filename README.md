# Volunteer-Hub
VolunteerHub is a volunteering opportunity board for cultural institutions, festivals, and associations. It works like a job board for volunteers.

## Team guide

Start with `docs/VolunteerHub-guide.html`: open it in a browser (double-click the file). It explains the project, the deliverables, the user journeys, the architecture, every class, the API, how to run and test the app, and how we work as a team.

## Projects

- `VolunteerHubDomain`: domain model (plain Java + JUnit tests), see its README
- `VolunteerHubService`: REST web service (Payara in Docker + Postman collection), see its README
